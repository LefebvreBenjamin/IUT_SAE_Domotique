Broches RFID-RC522 :
  SDA  --> 10
  SCK  --> 6
  MOSI --> 7
  MISO --> 2
  IRQ  --> NC
  GND  --> GND
  RST  --> 3
  3.3V --> 3V3

Broches BMP280 :
  VCC  -->  3V3
  GND  -->  GND
  SCL  -->  8
  SDA  -->  9
  CSB  -->  3V3
  SSD  -->  GND

Broches BH1750 :
  VCC -> 3V3 or 5V
  GND -> GND
  SCL -> 8
  SDA -> 9
  ADD -> NC/GND or VCC (see library doc : https://github.com/claws/BH1750 )

Broches Ecrans : https://electroniqueamateur.blogspot.com/2021/05/utilisation-dun-ecran-tactile-tft-spi.html
